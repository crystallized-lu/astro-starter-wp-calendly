# Astro Starter — WordPress backend, Calendly booking

A sprint-by-sprint build guide (docs, not a code dump) for a fast, bilingual
Astro site: static output, headless WordPress for content, Calendly for
booking, self-hosted forms, SEO/AEO, WCAG AA.

Start with [START-HERE.md](START-HERE.md). Point an AI coding agent at
[SKILL.md](SKILL.md), or read the sprints yourself — one at a time.

Extracted from a production site, not invented. A security-audit skill for
the finished build is bundled under `skills/vibe-security-audit/`.
